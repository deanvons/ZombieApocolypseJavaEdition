User Stories for ZombieApocalypse Game: 

As a user I want to:
- have different Survivor roles with different skills so that I can play more diverse
- perform different actions so that I can survive
- be able to load gear which I can use in actions
- have different attributes in different roles for customization
- be able to display details (gear, attributes, etc) for more transparency
- be able to see required items and skills to perform an action so that I know what I need
- see different action options to choose what I want to do
- calculate the effect of an action so that I know my progress
